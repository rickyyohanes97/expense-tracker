# Expense Tracker

A simple expense tracker built with HTML, CSS, and JavaScript. I made this project to practice JavaScript and build something useful for keeping track of personal finances.

## Features

- Add income and expense transactions
- Edit existing transactions
- Change a transaction's type
- Delete transactions
- Search transactions by description
- View total balance, income, and expenses
- Switch between light and dark mode
- Save transactions using Local Storage

## Built With

- HTML
- CSS
- JavaScript
- localStorage

## Getting Started

No installation is required.

1. Clone this repository:

   ```bash
   git clone https://github.com/rickyyohanes97/expense-tracker.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

## What I Practiced

While building this project, I practiced working with JavaScript arrays, DOM manipulation, event handling, form validation, and localStorage. I also worked on making the layout responsive and adding a dark mode toggle.
